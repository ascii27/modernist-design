# Table

Data tables on a native `<table class="table">`. Header cells are 11px uppercase (tracked 0.08em) at 60% ink over a 2px `color-divider` rule; body rows are 14px with 1px divider rules and a faint 4% ink hover tint. Cells pad `space-2`.

Reuse `.tag` for status cells and `.text-muted` for secondary columns. Keep numeric columns right-aligned with a local rule when you need one.

Contrast: header text (60% ink) is 4.2:1 on `color-bg` — kept exact from the source.
