# Tag

Small inline labels for status and category. Provide a `<span class="tag tag-…">` with one or two words.

- `.tag-accent` — `color-accent-800` on `color-accent-100` (9.8:1).
- `.tag-accent-2` — `color-accent-2-800` on `color-accent-2-100`; reads the same as accent in this mono scheme.
- `.tag-neutral` — `color-neutral-800` on `color-neutral-100` (9.3:1), for drafts and quiet states.
- `.tag-outline` — 1px `color-accent` border and text, for in-between states.

11px, tracked 0.02em, `3px 10px` padding, square corners. Don't use tags as buttons.
