# Navigation

The header bar: `<nav class="nav">` with a `.nav-brand` wordmark (18px heading face, pushes the links right), plain `<a>` links (14px, ink; hover and `aria-current="page"` turn `color-accent`), and optionally one `.btn-primary` at the end. A 2px `color-divider` rule closes the bar's bottom edge; padding is `space-3` × `space-4`.

There is no logo in the source — set the name in type. Hero copy under the bar stays flush left.
